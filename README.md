### Clipboard

The first puzzle was how to copy-and-paste into Omarchy running in a window on my Windows 11 machine, see this:

<https://omarchy.org/manual/unified-clipboard-history/>

These are probably the commands you need, "super" is the Windows key.

|Hotkey|Command|
|---|---|
|Super + C|Copy|
|Super + X|Cut|
|Super + V|Paste|
